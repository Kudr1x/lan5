# Лабораторная работа №5: Синхронизация хаотической системы Спротта (Case B)

Данный проект содержит полную программную реализацию, комплекс вычислительных экспериментов, интерактивное GUI-приложение и оформленный академический отчет по лабораторной работе №5 по курсу **«Моделирование нелинейных динамических систем»** (СПбГЭТУ «ЛЭТИ»).

---

## 1. Исследуемая модель и методы

### Система Спротта (Case B):
$$\begin{cases}
\dot{x} = y z \\
\dot{y} = x - y \\
\dot{z} = 1 - x y
\end{cases}$$

Дивергенция фазового потока: $\operatorname{div} F = \frac{\partial \dot{x}}{\partial x} + \frac{\partial \dot{y}}{\partial y} + \frac{\partial \dot{z}}{\partial z} = 0 - 1 + 0 = -1 < 0$ (система диссипативна).

---

### Численный метод: Симметричный обратимый интегратор CD (Composition Diagonal)
Композиция двух сопряженных полушагов с шагом $\tau = h/2$:
$$\Phi_{CD}(h) = \Phi^*_{CD}(h/2) \circ \Phi_{CD}(h/2)$$

1. **Подшаг 1 ($\Phi_{CD, \tau}$):** порядок обхода переменных $x \to y \to z$:
   $$x_{1} = x_n + \tau (y_n z_n + C_x)$$
   $$y_{1} = y_n + \tau (x_1 - y_n + C_y)$$
   $$z_{1} = z_n + \tau (1 - x_1 y_1 + C_z)$$

2. **Подшаг 2 ($\Phi^*_{CD, \tau}$, сопряженный):** порядок обхода $z \to y \to x$ с алгебраическим разрешением диагональной неявности по $y$:
   $$z_{n+1} = z_1 + \tau (1 - x_1 y_1 + C_z)$$
   $$y_{n+1} = \frac{y_1 + \tau (x_1 + C_y)}{1 + \tau}$$
   $$x_{n+1} = x_1 + \tau (y_{n+1} z_{n+1} + C_x)$$

**Свойство метода:** точная обратимость во времени $\Phi_{-h} = \Phi_h^{-1}$ с точностью машинного эпсилон ($|\Delta| < 10^{-16}$).

---

### Исследованные методы синхронизации:

1. **Однонаправленная синхронизация Пикоры — Кэрола (Pecora-Carroll):**
   К ведомой системе (Slave) добавляется диффузный контроллер:
   $$\dot{u}_s = f_u(X_s) + K (u_m - u_s), \quad u \in \{x, y, z\}$$
   Ведущая система (Master) развивается автономно.

2. **Двунаправленная (взаимная) синхронизация:**
   Контроллер ошибки вводится симметрично в обе системы:
   $$\dot{u}_m = f_u(X_m) + K (u_s - u_m)$$
   $$\dot{u}_s = f_u(X_s) + K (u_m - u_s)$$

3. **Быстрая обратимая синхронизация (Time-Reversible Synchronization):**
   *Методика статьи: Butusov D., Rybin V., Karimov A. «Fast time-reversible synchronization of chaotic systems», Physical Review E, 2025.*
   - Запись фрагмента траектории ведущей системы $X_m(t)$ на коротком окне $W_T$ ($W_T \sim 0.5 \dots 1.0$ с).
   - **Прямой ход (Forward):** $t_0 \to t_0 + W_T$ с шагом $+h$ и связью $+K^+ (X_m - X_s)$.
   - **Обратный ход (Backward):** $t_0 + W_T \to t_0$ назад во времени с шагом $-h$ и контроллером $-K^- (X_m - X_s)$.
   - Многократное повторение циклов обеспечивает суперокспоненциальную скорость локализации начального состояния ведомой системы.

## 3. Структура файлов проекта

- `sprott_sync.py` — высокопроизводительный расчетный модуль (ускорен с помощью Numba JIT) с реализацией интегратора CD и трех схем синхронизации.
- `run_experiments.py` — скрипт проведения полного цикла вычислительных экспериментов, генерирует 12 графиков высокого разрешения в папку `plots/`.
- `gui_sync.py` — интерактивное GUI-приложение (PyQt5) с 3D фазовыми портретами, временными рядами, диагоналями синхронизации и настройкой параметров в реальном времени.
- `build_report.py` — генератор официального отчета в формате DOCX (`Отчет_МНДС_ЛР5.docx`).
- `plots/` — сгенерированные графики высокого разрешения (DPI 200).
- `Fast time-reversible synchronization of chaotic systems.pdf` — статья авторов (Бутусов, Рыбин, Каримов, 2025).
